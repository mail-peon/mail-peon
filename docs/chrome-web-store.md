# Chrome Web Store 提交材料

## 隐私政策网址

商店的「隐私权政策网址」填这两个之一（同一份文件，后者是纯文本、渲染更稳）：

```
https://github.com/mail-peon/mail-peon/blob/main/docs/privacy-policy.md
https://raw.githubusercontent.com/mail-peon/mail-peon/main/docs/privacy-policy.md
```

内容见仓库内的 [privacy-policy.md](./privacy-policy.md)，其中第 13 节即为商店要求的数据使用（Limited Use）声明。

> ⚠️ 提交前先确认仓库是**公开**的，并且上面这个地址能在无痕窗口里匿名打开。
> 若默认分支不是 `main`，把地址里的分支名改掉。

## 单一用途说明

```
读取你授权的邮箱，挑出重要邮件并自动复制其中的验证码，所有数据只存本机。
```

---

## 需请求权限的理由

```
本扩展只做一件事：读取你自己授权的邮箱，把需要看的邮件挑出来并自动复制其中的验证码。所申请的 tabs / activeTab / alarms / sidePanel / identity / storage 与主机权限都只服务于这一件事，没有申请任何多余权限。
```

---

## 需请求 tabs 的理由

```
用于定位当前窗口的活动标签页，把「验证码已复制」的提示条投递到该页面的内容脚本。代码只查询当前活动的标签页并取其 id，不遍历、不记录、不上传任何标签页地址或浏览记录。
```

**需请求 activeTab 的理由**

```
当前版本代码中未使用该权限（定位标签页完全由 tabs 完成）。如实说明：这属于一份可以收窄的多余权限面，计划在下个版本评估移除。
```

**需请求 alarms 的理由**

```
用于注册一个低频（10 分钟）兜底任务：邮箱推送链路中断时仍能发现新邮件，并清理已失效的验证码。它不在后台采集任何数据。
```

**需请求 sidePanel 的理由**

```
扩展的完整界面（全部 / 重要 / 验证码 / 营销 分页的邮件流与 AI 摘要）用浏览器原生侧边栏展示，不向页面注入任何 UI。
```

**需请求 identity 的理由**

```
仅用于 Gmail 账号的 OAuth 授权：通过 chrome.identity.launchWebAuthFlow 打开 Google 官方授权页，用户同意后获取访问 token 以调用 Gmail API 收信。扩展不接触用户的 Google 账号密码，token 只存在本机。未连接 Gmail 的用户不会被使用该权限。
```

**需请求 storage 的理由**

```
仅用于读取早期版本遗留在 chrome.storage.local 中的旧配置，以完成一次性迁移；迁移校验无损后旧键即被删除。日常读写使用扩展自己的 IndexedDB，不需要任何权限，也不上传。
```

**需请求主机权限的理由**

```
https://gmail.googleapis.com/* —— 在你授权后读取你邮箱中的邮件（增量拉取，首次连接只记录同步位置、不拉取历史邮件）。
https://oauth2.googleapis.com/* —— 刷新 Gmail 的 OAuth 访问 token，以及在你断开账号时撤销授权。
*://*/* —— 扩展需要在你浏览的任意页面上显示「验证码已复制」的顶部提示条，因此内容脚本需匹配所有网址。该脚本不读取页面内容、不采集浏览记录、不修改页面外观、不拦截网络请求，空闲时不挂载任何 DOM。邮件相关的网络请求只会发往你自己配置的邮箱服务、本机 IMAP 中继与 AI 平台。
```

## 远程代码

选「不，我并未使用远程代码」

```
扩展的全部 JavaScript、依赖与提示词模板都打包在扩展程序包内，安装后不从任何服务器下载或执行代码，也未使用 eval()、new Function() 等动态执行方式（发布版 CSP 为 script-src 'self'）。网络请求只用于传输数据。
```

## 数据使用（勾选项）

| 类别 | 是否勾选 | 说明 |
| --- | --- | --- |
| 个人身份信息 | 否 | 不主动收集姓名、地址等；邮件中的签名信息归入「个人通讯」 |
| 健康信息 | 否 | 不涉及 |
| 财务和付款信息 | 否 | 不涉及 |
| 身份验证信息 | **是** | 邮箱密码 / OAuth token / AI Key 由用户填写，仅明文存储在本机 IndexedDB，用于登录用户自己选择的邮箱与 AI 服务 |
| 个人通讯 | **是** | 读取用户授权邮箱中的邮件（发件人、主题、时间、正文片段），存于本机；调用 AI 时发送主题、发件人、时间与正文前约 6000 字符 |
| 位置 | 否 | 不采集区域、GPS 等；调用 AI 平台时请求自然携带 IP，属 HTTPS 传输固有行为 |
| 网络记录 | 否 | 不记录用户访问过的网页 |
| 用户活动 | 否 | 不记录点击、滚屏、击键等 |
| 网站内容 | **是** | 仅当需要在当前页面显示提示条时与该页面的内容脚本通信；不读取、不上传网页内容 |

## 三个复选框

全部勾选（当前实现确实如此）。

## 其它提交项速查

- **远程代码**：否（见上）。
- **分发范围**：如需限制，注意 `*://*/*` 与内容脚本在所有页面注入是同一个原因的两种表述。
- **审核备注（可选）**：若审核员询问 `*://*/*` 的必要性，可指向隐私政策第 5.1 / 5.2 节 —— 它只为渲染验证码提示条，是唯一能被用户直接观察到的页面内行为；本仓库的 `ai-docs/decisions/open-questions.md` 记录了收窄为按需注入的备选方案。
